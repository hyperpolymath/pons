= pons wiki (source)

These are the source pages for the project wiki
(https://github.com/hyperpolymath/pons/wiki), authored for three audiences —
users, developers, and platform maintainers — plus the core concept pages.

They live here as well as on the wiki tab so the content is versioned under
CC-BY-SA-4.0 and reviewable via PR. Cross-page links use the wiki `+[[Page Name]]+`
convention, which resolves on the wiki tab.

Pages: `Home`, `Evidence-Tiers` (read first), `For-Users`, `For-Developers`,
`For-Platform-Maintainers`, `Rule-Catalogue`, `Roadmap`, plus `_Sidebar` /
`_Footer` navigation.

NOTE: To publish these to the GitHub *wiki tab*, the wiki must be initialised
once (create any first page via the web UI); after that the prepared
`pons.wiki.git` commit can be pushed and will replace it. Until then, this
directory is the canonical copy.
